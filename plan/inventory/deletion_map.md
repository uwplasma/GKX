## Deleted in this pull request

`gkx.utils.tomlcompat`, 30 lines. It existed only so a bare `import tomllib`
would not raise on Python 3.10. `requires-python` is `>=3.11`, `tomli` is not a
declared dependency, and the fallback branch carried `# pragma: no cover`
because it was unreachable. Nineteen files now import `tomllib` directly. The
release gate that *required* the shim was inverted to forbid the backport
instead, and the test asserting the shim imported cheaply was removed with it.

No other deletion belongs in A1-1; the plan reserves large moves for Phase A
proper.
